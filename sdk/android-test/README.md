# Проверка сигнала звонка на телефоне

Маленькое приложение с одним экраном. Оно показывает, видит ли модуль
([../android/CallSignal.kt](../android/CallSignal.kt)) звонок на настоящем телефоне, и ведёт журнал
изменений. Разрешений у приложения нет — это и проверяется.

Проект собирается из тех же файлов `sdk/android`, которые встраивает банк, а не из их копии.

## Что нужно

- Android Studio: https://developer.android.com/studio
- Телефон на Android 7.0 или новее и кабель USB.
- Второй телефон или человек, которому можно позвонить.

## Шаги

1. Установите Android Studio с настройками по умолчанию.
2. В Android Studio: **File → Open** и выберите папку `sdk/android-test`.
3. Дождитесь конца синхронизации (первый раз — несколько минут, нужен интернет). Если Studio
   предложит установить недостающие части SDK или обновить плагин Gradle — соглашайтесь.
4. На телефоне включите режим разработчика: **Настройки → О телефоне** → семь раз нажмите на
   «Номер сборки». Затем **Настройки → Для разработчиков → Отладка по USB**.
5. Подключите телефон кабелем и разрешите отладку в окне на телефоне.
6. В Android Studio выберите телефон в списке устройств вверху и нажмите зелёную кнопку **Run**.

## Что проверить

Приложение должно быть на экране, пока идёт разговор: примите или начните звонок, затем вернитесь
в приложение.

| Проверка | Что должно быть на экране |
|---|---|
| Звонка нет | «На звонке: НЕТ», режим `NORMAL` |
| Обычный звонок по сотовой сети | «На звонке: ДА», режим `IN_CALL` |
| Звонок в WhatsApp | «На звонке: ДА», режим `IN_COMMUNICATION` |
| Звонок в Telegram | то же |
| Звонок закончился | снова «НЕТ», в журнале новая строка |
| Кнопка «Показать предупреждение» | окно с двумя кнопками |

В журнале у каждой строки указано, что заметило изменение: `опрос` (раз в секунду) или
`слушатель` (сразу, только Android 12+).

Запишите модель телефона, версию Android и результат по каждой строке. Если мессенджер во время
звонка показывает «НЕТ» — это то ограничение, о котором сказано в
[docs/INTEGRATION.md](../../docs/INTEGRATION.md): режим звонка выставляет сам мессенджер.
